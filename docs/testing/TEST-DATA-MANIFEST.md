## Admission checklist

- [x] Artifact has a stable ID and checksum.
- [x] Source and derivation are reproducible.
- [x] Rights and intended use are recorded.
- [x] Sensitive data is excluded from Git and ordinary CI.
- [x] Expected behavior and approving reviewer are recorded.
- [x] Retention and deletion authority are recorded.
- [ ] Generated defects were checked for artificial cues. *(Not applicable: no seeded-defect artifact exists yet.)*
