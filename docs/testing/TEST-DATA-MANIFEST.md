- [x] Artifact has a stable ID and checksum.
- [x] Source and derivation are reproducible.
- [x] Rights and intended use are recorded.
- [x] Sensitive data is excluded from Git and ordinary CI.
- [x] Expected behavior and approving reviewer are recorded.
- [x] Retention and deletion authority are recorded.
- [ ] Generated defects were checked for artificial cues. *(Not applicable: no seeded-defect artifact exists yet.)*

The active E0 lesson, tone, voice-profile, and contract fixtures satisfy the applicable admission items. The generated tone and protocol metadata are not listening-quality or defect-detection artifacts, so artificial-cue review does not apply; that item becomes live when `asr-seeded-defects-v1` is created under ADR-0005.

`t3_e0_registered_fixture_checksums_match_test_data_manifest` verifies every active audio, lesson, and contract fixture checksum above against the committed bytes. Editing a fixture without updating its row fails CI.

The three `fixtures/audio/` files are regenerated by `cargo run --package study-tts-testkit --example generate-audio-fixtures`; the generator is the authoritative derivation and the committed bytes are what the tests read. Only the committed bytes are checked: editing a fixture without updating its row fails, and so does adding one without a row, but a change to the generator alone passes until the fixtures are regenerated and their rows updated. Regenerate and update the rows in the same commit as a generator change.
